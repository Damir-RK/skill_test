# Популярные команды Claude Code

Команды делятся на два типа:

- **Slash-команды** начинаются с `/` и вводятся **внутри интерактивного сеанса** Claude Code.
- **CLI-команды и параметры** начинаются с `claude` и запускаются **в терминале** (PowerShell, cmd или bash).

Наберите `/` или выполните `/help`, чтобы увидеть команды, доступные именно в вашей установке. Список может зависеть от версии, настроек, проекта и подключённых плагинов или skills.

## Slash-команды

| Команда | Что делает | Когда применять |
|---|---|---|
| `/help` | Показывает справку и доступные команды. | Когда нужно найти команду или вспомнить её синтаксис. |
| `/clear` | Начинает новый разговор, очищая контекст текущего сеанса. | Когда переходите к несвязанной задаче. Для сохранения полезного контекста используйте `/compact`. |
| `/compact [инструкции]` | Сжимает историю разговора; необязательными инструкциями можно указать, что важно сохранить. | В длинном сеансе, чтобы освободить место в контексте и продолжить работу. |
| `/model [модель]` | Показывает выбор моделей или переключает активную модель. | Когда хотите выбрать другую модель для текущей задачи. Доступные модели зависят от аккаунта и конфигурации. |
| `/permissions` | Просматривает и настраивает разрешения инструментов Claude Code. | Чтобы проверить или изменить, какие действия требуют подтверждения. Не заменяет политики организации. |
| `/config` | Открывает интерактивные настройки Claude Code. | Для настройки доступных параметров, например модели или темы. |
| `/status` | Показывает сведения о текущем сеансе и конфигурации. | При диагностике: проверить активную модель, аккаунт или настройки. |
| `/init` | Анализирует проект и помогает создать `CLAUDE.md` с инструкциями для Claude Code. | При первом запуске в проекте. Проверьте и поправьте предложенный файл под правила проекта. |
| `/memory` | Помогает просматривать и редактировать инструкции и память, включая `CLAUDE.md`. | Чтобы управлять проектными указаниями, которые Claude Code должен учитывать между задачами. |
| `/resume` | Открывает выбор предыдущих сеансов для возобновления. | Когда нужно вернуться к ранее начатой работе. |
| `/plan` | Переключает Claude Code в режим планирования. | Для больших или неоднозначных изменений, когда сначала полезно обсудить план, а затем редактировать код. |
| `/doctor` | Проверяет состояние установки и конфигурации Claude Code. | Когда CLI или интеграция работает неправильно. Также доступна команда `claude doctor` в терминале. |
| `/bug` | Открывает отправку отзыва о проблеме. | Чтобы сообщить о дефекте или предложить улучшение. |
| `/exit` | Завершает интерактивный сеанс. | Когда закончили работу. |

## CLI-команды и параметры

| Команда | Что делает | Когда применять |
|---|---|---|
| `claude` | Запускает интерактивный сеанс в текущей папке. | Для обычной работы с проектом через терминал. |
| `claude "объясни этот проект"` | Запускает сеанс и передаёт начальный запрос. | Чтобы сразу начать с конкретной задачи. |
| `claude -p "объясни эту функцию"` | Выполняет запрос без интерактивного диалога и завершает работу; `-p` — короткая форма `--print`. | Для скриптов, автоматизации и одноразовых запросов из командной строки. |
| `Get-Content .\logs.txt \| claude -p "объясни журнал"` | Передаёт содержимое файла в Claude через stdin (синтаксис PowerShell). | Для анализа файла или вывода другой команды без ручного копирования. В bash синтаксис конвейера такой же, но для чтения файла обычно используют `cat logs.txt \| claude -p "объясни журнал"`. |
| `claude -c` | Продолжает последний сеанс в текущей папке; `-c` — короткая форма `--continue`. | Чтобы продолжить недавно прерванную работу. |
| `claude -c -p "проверь ошибки типов"` | Продолжает последний сеанс и выполняет запрос в неинтерактивном режиме. | Для автоматизированного продолжения контекста предыдущей работы. |
| `claude -r "имя-сеанса" "продолжи задачу"` | Возобновляет сеанс по его имени или идентификатору; `-r` — короткая форма `--resume`. | Чтобы выбрать конкретный старый сеанс, а не только последний. |
| `claude update` | Обновляет Claude Code. | Чтобы установить актуальную версию CLI. |
| `claude install stable` | Устанавливает стабильный канал Claude Code через native installer. | Для установки или выбора стабильного канала; точные варианты и требования смотрите в документации установки. |
| `claude doctor` | Запускает диагностику из терминала. | Для проверки установки, если команда запускается с ошибкой. |

### Полезные параметры запуска

| Параметр | Назначение | Пример |
|---|---|---|
| `--model <модель>` | Выбирает модель для запуска. | `claude --model <модель>` |
| `--add-dir <путь>` | Добавляет дополнительную папку в рабочий контекст Claude Code. | `claude --add-dir ..\shared` |
| `--permission-mode <режим>` | Задаёт режим разрешений для сеанса. | `claude --permission-mode <режим>` |

Допустимые значения параметров и дополнительные опции могут меняться — сверяйтесь с официальным CLI Reference.

## Быстрый выбор

- **Начать новую задачу:** `/clear`.
- **Продолжить текущую работу после длинного разговора:** `/compact`.
- **Продолжить последний сеанс из терминала:** `claude -c`.
- **Вернуться к конкретному старому сеансу:** `claude -r "имя-сеанса"`.
- **Сначала продумать крупную задачу:** `/plan`.
- **Подготовить инструкции для нового проекта:** `/init`, затем проверить `CLAUDE.md`.
- **Проверить доступные команды:** `/help` или просто набрать `/`.
- **Диагностировать проблемы установки:** `/doctor` или `claude doctor`.
